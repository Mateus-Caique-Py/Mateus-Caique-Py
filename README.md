## 👨‍💻 Sobre mim

Trabalho com **banco de dados SQL Server (T-SQL)**, atuando na **manutenção e otimização de queries**, análise de desempenho e sustentação de rotinas de dados. Paralelamente, desenvolvo aplicações **back-end** e **automações** — principalmente em **Python** e **C# / .NET** — com foco em integração entre sistemas, APIs e bancos de dados.

- 🗄️ **Dados:** escrita e tuning de consultas, procedures e rotinas em T-SQL
- ⚙️ **Back-end:** APIs, workers e integrações com Python, C# / .NET e Node.js
- 🤖 **Automação:** bots, scripts e ferramentas que eliminam tarefas manuais e repetitivas
- 🏗️ **Boas práticas:** Clean Architecture, separação em camadas, testes e versionamento com Git
- 🌱 **Estudando agora:** arquitetura de software, Docker, PostgreSQL e cloud

> Gosto de transformar processos manuais em código: se algo é feito duas vezes, eu automatizo.
